# Recallo

Десктопное приложение для запоминания слов и фраз на английском и испанском: активное воспроизведение ответа и интервальное повторение (FSRS).

Требования: [duocards_requirements.md](duocards_requirements.md). Решения: [PLAN.md](PLAN.md). Фазы и решения D14+: [ROADMAP.md](ROADMAP.md). Установка на другой Mac: [DEPLOY.md](DEPLOY.md). Заметки для ИИ-агентов: [AGENTS.md](AGENTS.md). Текущая версия — 0.11.2.

## Возможности

- **Два языка** — English и Spanish, у каждого свои карточки, наборы, прогресс и статистика.
- **Карточки**: слово, значение на любом языке, примеры (слово в них скрывается на лицевой стороне), эмодзи-ассоциация, транскрипция. У испанского два варианта произношения — 🇦🇷 Argentina и 🇪🇸 Spain, у каждого своя озвучка.
- **Обучение**: первая встреча с новым словом — карточка целиком (слово, произношение, значение, примеры) с ярлыком «New word» и одной кнопкой «Continue», без самооценки; затем вспоминание (значение → слово) с интервальным повторением FSRS. Анимации: переворот карточки при показе ответа; после нового слова карточка уходит в сторону, следующее новое слово появляется справа, а вспоминание поднимается снизу. Новые слова не идут подряд: после знакомства — уже знакомое слово (раньше срока, если наступивших нет), а при учёбе набора — и выученные слова этого набора, ближайшие к повторению. Свайп или клавиши ← / →, отмена последней оценки (⌘Z), правка карточки посреди сессии. Шапка сессии — одна компактная строка: набор, счётчики ✨ новые · ✓ вспомнил · ✗ забыл, таймер, ↶ и End session. У кнопок-значков ↶, ✎, 🗑 и у счётчиков — быстрые подсказки при наведении; у кнопок с текстом и у 🔊 подсказок нет.
- **Поиск и фильтр в Cards**: поиск по части слова, по словам фразы в любом порядке, в значениях, примерах, переводах и названиях наборов, с прощением одной опечатки в словах от 5 букв; лучшие совпадения — первыми. Кнопки фильтра по статусу (New, Introduced, Learning, Review, Relearning) с числом карточек.
- **Удаление посреди сессии**: корзина в углу карточки Study — с подтверждением, затем сразу следующая карточка.
- **Режим ввода ответа** (Answer: Type на экране Study): слово нужно напечатать; приложение прощает регистр, ударения, пунктуацию и одну опечатку и предлагает оценку, но окончательно решаете вы — «I was right» или «Count as forgot».
- **Лимит новых слов в день** (Settings → Study, по умолчанию 10): повторения не ограничиваются; когда лимит исчерпан, можно разово взять ещё 5. Если лимит кончился посреди сессии и остались только повторения позже, Study предлагает выбор: «Practice current words» (повторять начатые слова без ожидания до конца сессии) или «Learn 5 new words».
- **Сессии по таймеру**: No limit, 5, 10 или 15 минут; по окончании — итог и продление на 5 / 10 / 15 минут.
- **Today's swell** — волна дня: высота в метрах растёт от регулярных занятий, точных ответов и освоенных слов.
- **Наборы**, поиск, импорт (Recallo CSV/JSON, DuoCards, Quizlet), экспорт словаря, полная резервная копия и восстановление.
- **Автоматическая резервная копия** раз в день (Settings → Backup): хранятся 7 последних дней и по одной копии за 4 предыдущие недели.
- **Тема оформления** — System, Light или Dark (Settings → Appearance).
- **Stats**: стадии слов, активность за 14 дней, серия дней, трудные слова.
- **Agent API и MCP**: Claude и другие агенты могут читать и править карточки и наборы (выключено по умолчанию).

## Голоса

Озвучка использует голоса macOS. Какой голос звучит для каждого варианта, видно в **Settings → Voices**. Если нужного голоса нет (например, аргентинского), установите его: «Системные настройки → Универсальный доступ → Устная речь (Spoken Content) → Системный голос → Управлять голосами…» → Spanish → Argentina (Diego), затем перезапустите Recallo. Пока его нет, у аргентинского варианта показывается только транскрипция, а прослушать можно испанский (🇪🇸) вариант. Если у голоса есть улучшенная версия (Enhanced или Premium), Recallo выбирает её. Символы вроде ¿ ¡ и « / » голос не зачитывает: перед озвучкой текст очищается.

## Recallo: Mobile на iPhone

Отдельная установка Recallo для iPhone — те же экраны и правила обучения, свои данные, без синхронизации с Mac. Работает без сети. Адрес: **https://k-coder-design.github.io/recallo/** (iOS 17 и новее).

1. Откройте адрес в **Safari** на iPhone → кнопка «Поделиться» → **«На экран „Домой“»** → «Добавить». Дальше открывайте Recallo значком.
2. Перенос слов с Mac (один раз): на Mac в Recallo — Settings → Backup → **Create backup…**, файл — в iCloud Drive или по AirDrop на iPhone. На iPhone в Recallo — Settings → Backup → **Restore from backup…** → выбрать файл → **Replace and restore**.
3. Новые слова: агент готовит файл импорта (Recallo JSON), его открывают в Cards → «⋯» → **Import cards**. MCP и Agent API на телефоне нет.
4. Копия: Settings → Backup → **Create backup…** (меню «Поделиться» → «Сохранить в Файлы»). Если копии не было неделю, Study напоминает. Удаление значка Recallo удаляет его данные.
5. Обновления приходят сами: когда выйдет новая версия, внизу появится «New version ready · **Update**».

Публикация: каждый push в ветку main репозитория https://github.com/k-coder-design/recallo собирает телефонную сборку и выкладывает её на GitHub Pages (`.github/workflows/pages.yml`). Решения — D57–D60 в ROADMAP.md.

## Запуск

Обычный запуск — приложение **Recallo** в «Программах» (или в Dock). После изменений кода переустановить: `npm run install:mac` (Recallo должен быть закрыт).

Для разработки нужен Node.js 22+ и macOS 13+.

```bash
npm ci
```

```bash
npm run dev
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Приложение в режиме разработки с горячей перезагрузкой |
| `npm run build` | Сборка в `out/` |
| `npm start` | Запуск собранного приложения |
| `npm test` | Тесты (Vitest через Electron в режиме Node, чтобы better-sqlite3 был той же сборки). Тесты ядра идут дважды: проект `mac` — на better-sqlite3, проект `phone` — на SQLite WebAssembly; только один: `npm test -- --project phone` |
| `npm run typecheck` | Проверка типов main/preload, интерфейса и телефонной сборки |
| `npm run build:mobile` | Recallo: Mobile — веб-приложение для iPhone в `dist/mobile/` (в разработке, см. ROADMAP, D57) |
| `npm run dev:mobile` | Телефонная сборка в режиме разработки в браузере |
| `npm run import:set -- <файл.json> [--dry-run]` | Загрузить набор из `data/sets/*.json` (создаёт набор, дубли пропускает) |
| `npm run dist:mac` | Собрать Recallo.app под архитектуру этого Mac (`dist/mac-arm64/` или `dist/mac/`) |
| `npm run install:mac` | Собрать и установить Recallo в «Программы» |
| `npm run release:mac` | Собрать DMG для Apple Silicon и Intel: `dist/Recallo-<версия>-arm64.dmg`, `…-x64.dmg` |
| `npm run kit:mac` | Комплект для другого Mac — папка `dist/kit/Recallo-<версия>/` и её архив `.zip` для отправки: оба DMG, скрипт обновления, архив исходников, START_HERE / DEPLOY / UPGRADE, контрольные суммы |
| `bash scripts/setup-mac.sh` | Установка из исходников на новом Mac одной командой (см. DEPLOY.md) |
| `npm run import:duocards -- <файл.csv> [--space en|es] [--dry-run]` | Загрузить CSV-экспорт DuoCards (front, back, hint) как карточки; дубли по слову пропускаются |

Данные хранятся в SQLite: `~/Library/Application Support/Recallo/recallo.sqlite`, автокопии — рядом, в папке `backups/`.
Для экспериментов можно указать отдельную папку: `RECALLO_USER_DATA=/путь/к/папке npm run dev`.

## Установка на другой Mac

Полная инструкция — [DEPLOY.md](DEPLOY.md); она же годится для ИИ-агента. Коротко:

1. Здесь: `npm run kit:mac` — в `dist/kit/` появятся папка `Recallo-<версия>` (DMG для Apple Silicon и Intel, скрипт обновления, архив исходников, инструкции) и её архив `Recallo-<версия>.zip`, который и отправляют. Обновление уже установленного Recallo — `bash upgrade-mac.sh` из комплекта, подробно в [UPGRADE.md](UPGRADE.md).
2. На другом Mac: открыть DMG под свою архитектуру (`uname -m`: `arm64` или `x86_64`) и перетащить Recallo в «Программы». Приложение не нотаризовано Apple: при первом запуске — правый клик → «Открыть» или «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Либо собрать из исходников: `bash scripts/setup-mac.sh`.
3. Через ИИ-агента: распаковать комплект, открыть папку в агенте и вставить текст из [AGENT_PROMPT.md](AGENT_PROMPT.md) — агент установит Recallo по DEPLOY.md и подключит MCP.
4. Слова и прогресс (по желанию): на старом Mac — Settings → Backup → Create backup (или последняя автокопия из `backups/`), на новом — Restore from backup.

## API и MCP для агентов

- Включается в **Settings → Agent API** (по умолчанию выключен). REST API: `http://127.0.0.1:47821/api/v1`, токен — в Settings, описание — `/api/v1/openapi.json`.
- MCP-сервер встроен в приложение. Подключение к Claude Code (один раз):

```bash
claude mcp add --scope user recallo -e ELECTRON_RUN_AS_NODE=1 -- "/Applications/Recallo.app/Contents/MacOS/Recallo" "/Applications/Recallo.app/Contents/Resources/app.asar/out/mcp/index.cjs"
```

  Фрагмент для Claude Desktop — в Settings. Агент работает, пока Recallo открыт и Agent API включён.

- ИИ-помощь с карточками — через агента: например, «добавь в набор Travel and everyday life слова boarding pass, jet lag с примерами» или «допиши примеры карточкам набора Formal verbs». Агент сам подбирает значение, 1–3 примера с переводом на языке значения и эмодзи; транскрипцию и скрытие слова в примерах Recallo добавляет сам.

## Устройство

```
src/
  shared/      типы, контракт IPC, маскирование, варианты произношения, таймер сессии
  main/
    db/        подключение к SQLite и миграции; интерфейс Db (types.ts) и база WebAssembly для телефона (wasm.ts)
    domain/    карточки, планировщик FSRS, сессия обучения — вся бизнес-логика
    ipc.ts     мост интерфейс ↔ домен, единая структура ошибок
    autoBackup.ts  ежедневная автоматическая копия в backups/
  preload/     безопасный мост window.recallo (contextIsolation + sandbox)
  renderer/    интерфейс на React
  main/api/    REST API для агентов (node:http) и OpenAPI
  mcp/         MCP-сервер (stdio), собирается в out/mcp/index.cjs
  mobile/      Recallo: Mobile (D57): мост window.recallo → Web Worker с тем же ядром на SQLite WebAssembly
scripts/      импорт (DuoCards, наборы), сборка, установка и обновление на macOS (mac-app.mjs, setup-mac.sh, make-kit.sh, upgrade-mac.sh)
```

- Бизнес-правила живут только в `src/main/domain`; интерфейс (через IPC), REST API и MCP вызывают один и тот же слой.
- Содержимое карточек (`cards`, `examples`), прогресс (`card_progress`) и история (`review_log`) хранятся раздельно.
- Лицевая сторона приходит из main уже без изучаемого выражения; оценка принимается только после раскрытия и только один раз на показ.
- Интерфейс по умолчанию на английском; содержимое карточек — на любом языке.
