# Промпты для ИИ-агента (Claude Code и др.)

Откройте папку комплекта в агенте и вставьте целиком один из текстов ниже: «Новая установка» — если Recallo на этом Mac ещё нет, «Обновление» — если он уже стоит.

## Новая установка

---

В этой папке — комплект приложения Recallo (macOS). Установи его на этот Mac строго по инструкции `DEPLOY.md` из этой же папки и отчитайся по пунктам.

1. Определи архитектуру (`uname -m`) и версию macOS (нужна 13+). Проверь контрольные суммы: `shasum -a 256 -c SHA256SUMS.txt`.
2. Установи приложение по «Варианту A» (DMG под эту архитектуру → `/Applications/Recallo.app`). Если не получится — по «Варианту B» (сборка из `Recallo-*-source.zip` скриптом `scripts/setup-mac.sh`; Node.js 22+ при необходимости поставь через Homebrew, спросив меня). Если Recallo уже установлен, остановись и скажи мне: для этого случая есть промпт «Обновление».
3. Слова и прогресс не переноси: Recallo должен начать с пустой базы. Ничего не копируй в `~/Library/Application Support/Recallo/`.
4. Запусти Recallo (`open -a Recallo`) и проверь: версия (`defaults read /Applications/Recallo.app/Contents/Info.plist CFBundleShortVersionString`), окно открылось. Если первый запуск блокирует Gatekeeper — сделай, как сказано в DEPLOY.md («Вариант A»), объяснив мне, что делаешь.
5. Подключи Recallo к Claude Code по разделу «Подключение Claude (MCP)». Agent API в новой установке выключен — попроси меня включить его в Settings → Agent API, затем проверь `claude mcp list` → `recallo … ✔ Connected` и вызови `list_sets` для English — должен вернуться пустой список.
6. Системные настройки сам не меняй. Напомни мне установить аргентинский голос для озвучки (раздел «Голоса для озвучки») и что проверить его можно в Settings → Voices.
7. В конце коротко отчитайся: что установлено и какой вариант сработал, подключён ли MCP, что мне осталось сделать вручную.

## Обновление

---

В этой папке — новая версия Recallo (macOS), а на этом Mac Recallo уже установлен и в нём мои слова. Обнови его строго по `UPGRADE.md` из этой же папки, ничего не потеряв, и отчитайся по пунктам.

1. Узнай установленную версию (`defaults read /Applications/Recallo.app/Contents/Info.plist CFBundleShortVersionString`) и сколько сейчас карточек (`sqlite3 ~/Library/Application\ Support/Recallo/recallo.sqlite "SELECT COUNT(*) FROM cards"`). Если установлена та же или более новая версия, чем в комплекте, — скажи мне и остановись.
2. Проверь, открыт ли Recallo (`osascript -e 'application "Recallo" is running'`). Если открыт — спроси меня, можно ли его закрыть, и закрывай только после моего «да» (`osascript -e 'quit app "Recallo"'`).
3. Запусти `bash upgrade-mac.sh` из этой папки. Он сам проверит DMG, сделает копию базы и заменит приложение. Если скрипт остановился с ошибкой — перескажи мне её и ничего не исправляй сам; базу и файлы в `~/Library/Application Support/Recallo/` вручную не меняй.
4. Запусти Recallo (`open -a Recallo`) и сверь по разделу «Проверка после обновления»: версия новая, `PRAGMA user_version` = 8, карточек столько же, сколько было в шаге 1. Если первый запуск блокирует Gatekeeper — сделай, как сказано в DEPLOY.md («Вариант A»), объяснив мне, что делаешь.
5. Подключение Claude (MCP) после обновления менять не нужно — проверь только `claude mcp list`, если он был настроен.
6. В конце коротко отчитайся: с какой версии на какую обновил, где лежит копия базы, совпало ли число карточек и что мне осталось сделать вручную.
