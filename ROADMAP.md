## MVP-1. Ручное обучение

Цель: можно завести карточки на английском и испанском и учить их с интервальным повторением.

- Каркас: Electron + Vite + React + TypeScript, SQLite с миграциями, доменный слой в main-процессе, типизированный IPC.
- Языковые пространства EN/ES, переключение без потери прогресса (LANG-01…04, 06).
- Карточки: создание, просмотр, редактирование, удаление; несколько примеров с переводом; стабильные UUID; защита от перезаписи по `version` (CARD-01…04, API-15 на уровне домена).
- Явный сброс прогресса при редактировании (CARD-05).
- Маскирование: все вхождения выражения, простые словоформы, явные фрагменты для изменённых форм, предпросмотр и предупреждение в редакторе (CARD-06…10).
- Сессия обучения: лицевая/обратная сторона, свайп мышью, кнопки, клавиши ←/→/Пробел, оценка только после раскрытия (LEARN-01…09; область — все карточки языка).
- FSRS (`ts-fsrs`), шаги 1 мин → 10 мин, просроченные раньше новых, повтор после ошибки с другими карточками между показами, без бесконечного цикла (SRS-01…11, 13).
- Идемпотентная оценка: повторная отправка не создаёт второй результат (LEARN-10, GEN-03).
- Счётчики «к повторению / новые» (GEN-05).
- Озвучивание эталона на обратной стороне голосами ОС (CARD-12, 13).
- Тесты: маскирование, планировщик, очередь, идемпотентность, разделение языков.

Критерии приёмки раздела 13: 1, 2, 3, 7, 9, 12 (для оценок).

Итог: 30 автотестов (маскирование, карточки, сессия) и сквозной сценарий в собранном приложении проходят.
Не проверено: озвучивание вслух (кнопка вызывает голоса ОС, звук автоматически не проверялся).

## MVP-3. API и MCP-сервер для агентов

Цель: агенты (Claude Desktop, Claude Code и другие) читают и пополняют словарь — прямо из разговора, без ручных HTTP-запросов.

**REST API**

- Локальный REST (Fastify) на `127.0.0.1`, bearer-токен из настроек (API-08).
- Все операции 8.1, массовое создание и обновление с результатом по каждому элементу (API-01…07, 13).
- OpenAPI с примерами (API-09), единая структура ошибок (API-12).
- `Idempotency-Key` (API-14), `If-Match`/`version` → 409 (API-15).
- Явная политика удаления набора, запрос без неё отклоняется (SET-11).
- Данные для маскирования в ответах (API-18); история и аудио агенту не нужны (API-17).

**MCP-сервер** (D25)

- Отдельный локальный MCP-сервер (stdio), работающий поверх того же REST API: те же проверки, токен и бизнес-правила (API-10), никакой отдельной логики и прямого доступа к базе.
- Инструменты: поиск карточек, список языков и наборов, добавление слов (одного и пачкой, с результатом по каждому и предупреждением о дублях), правка карточки, перенос в набор, удаление набора с явной политикой (SET-11).
- Повтор вызова агентом не создаёт дублей: инструменты передают ключ идемпотентности в API (API-14).
- Если приложение не запущено, инструмент возвращает понятную ошибку («Open Recallo and try again»), а не падает.
- В настройках приложения — токен и готовый фрагмент конфигурации для подключения к Claude Desktop и Claude Code.
- Пример сценария: «добавь в Recallo слова из этого текста» → агент создаёт карточки с примерами, а транскрипция и маскирование заполняются приложением.

Критерии приёмки: 11, 12 (для создания); агент через MCP добавляет, находит и правит карточки, повторный вызов не создаёт дублей.

Итог: REST API на `node:http` (D35) с токеном, проверкой Host, без CORS, идемпотентностью, защитой версий, массовыми операциями и OpenAPI 3.1; MCP-сервер с 10 инструментами внутри Recallo.app (D36); вкладка Settings с выключателем, портом, токеном и инструкциями. 139 автотестов (в т. ч. API по HTTP и MCP по протоколу) и три сквозных сценария проходят; MCP проверен из установленного приложения по stdio. Recallo подключён к Claude Code пользователя (`claude mcp add --scope user`, «✔ Connected»), Agent API включён по решению пользователя.

## Дизайн «Серфинг» и сессии по таймеру, версия 0.5.0

Обучение как серфинг: чем стабильнее занимаешься, тем выше волна, которую можешь покорить. Совмещены два референса: спокойная гамма побережья для экранов обучения и типографика с коралловыми акцентами ретро-постера для заголовков, кнопок и достижений (D41).

- Новая тема: кремовый «песок», бирюзовая вода, коралловые акценты, заголовки Futura в верхнем регистре, верхняя панель с волнистым краем. Светлая и тёмная тема; цвета графиков проверены валидатором палитры, контраст текста не ниже 4.7:1.
- **Today's swell** на Study, в итоге сессии и в Stats: высота волны в метрах (0.3–4.0) с подписью от Flat до Overhead, иллюстрация волн, высота которых зависит от swell, и подсказка, как вырасти: «Paddle out today → 2.1 m» / «Come back tomorrow → 2.0 m». Формула — D40. Расписание FSRS не меняется.
- Метафора в тексте: кнопка «Paddle out», «waves to ride» (к повторению) и «calm water» (новые), стадии слов в Stats: calm water → ripples → small waves → rolling waves → big waves.

- **Сессии по таймеру** (D43): перед стартом выбирается длительность — No limit, 5, 10 или 15 минут (выбор запоминается). Во время сессии виден отсчёт. Когда время вышло, текущая карточка дорабатывается до оценки («Last card»), затем экран «Time’s up» с итогом и вариантами «Extend by 5 / 10 / 15 min» и «Finish»; там же можно отменить последний ответ. Если в этот момент ждём короткого повторения, итог показывается сразу. Прогресс сохраняется как обычно.

Итог: 170 автотестов и пять сквозных сценариев (58 проверок) проходят. Установлено в /Applications как 0.5.0, копия базы до установки — `recallo.before-surf.sqlite`.

Перед озвучкой текст очищается: без ¿ и ¡, « / » между вариантами — пауза, слэш внутри фразы — «or»/«o», sth/sb — something/somebody. ## ~~MVP-6. ИИ-генерация содержимого карточек~~ — отменена

Отменена по решению пользователя 24.10.2026 (D46): карточки со значениями и примерами создаёт Claude через MCP (MVP-3), отдельная кнопка в редакторе не нужна. Из плана сохранено правило перевода примеров — на языке значения; оно добавлено в описание MCP-инструментов. Ниже — исходный план для истории.

Цель: быстрее создавать карточки — по слову ИИ предлагает содержимое, пользователь проверяет и правит (раздел 11 требований: «AI-подготовка определений и примеров»). D26.

- В редакторе карточки кнопка «Suggest with AI»: по слову (и языку пространства) ИИ предлагает:
  - **значение** — на выбранном пользователем языке: English, Russian или Spanish. Язык выбирается в редакторе; по умолчанию — последний использованный для этого пространства (настройка запоминается);
  - **примеры использования** (1–3), где выражение употреблено естественно; для изменённых форм ИИ сразу указывает фрагменты для скрытия (CARD-09);
  - **перевод примеров**.
  - **эмодзи-ассоциацию** — точнее офлайн-подбора из D27; заменяет только автоматически подобранные эмодзи, выбор пользователя не трогает (`emoji_auto`).
- Ничего не сохраняется само: предложение подставляется в поля редактора как черновик, пользователь правит и нажимает Save (те же проверки, что и при ручном вводе, API-10). Можно принять поле частично или запросить другой вариант.
- Предупреждения редактора работают и для предложенного текста: значение не должно содержать само выражение (раздел 3.2), выражение должно находиться в каждом примере.
- Ключ ИИ-провайдера хранится в Keychain и используется только в main-процессе; в интерфейс и ответы API не попадает (по аналогии с VOICE-19). Перед первым запросом — уведомление, что слово отправляется внешнему сервису.
- Ошибка или недоступность сервиса не блокирует ручной ввод (по аналогии с GEN-04).
- Агенты через MCP (MVP-3) могут создавать карточки сами — генерация в редакторе нужна для ручного сценария.

Открытые вопросы перед реализацией: провайдер и модель (кандидат — Claude API), стоимость и лимиты; на какой язык переводить примеры, если значение на изучаемом языке; нужна ли пакетная генерация для уже существующих карточек без примеров.

## MVP-7. Лимит новых слов в день

Цель: ровная нагрузка. Сейчас лимита нет: если познакомиться с 30–40 словами за раз, через пару дней накапливается большая очередь повторений. Запрошено 24.10.2026.

- Настройка в Settings → Study: «New words per day» для каждого языка отдельно, по умолчанию 10; 0 — только повторения, без новых слов.
- Лимит считает знакомства за сегодняшний день (по местному времени) во всём языке — независимо от того, какой набор выбран для обучения. Отмена знакомства (⌘Z) возвращает слово в лимит.
- Повторения лимит не ограничивает: карточки «To review» показываются всегда.
- Study: счётчик «New» показывает, сколько новых слов осталось на сегодня (не больше лимита), рядом — «4 of 10 new words today». Когда лимит исчерпан, а новые слова ещё есть, — сообщение и кнопка «Learn 5 more today» (разовое увеличение только на сегодня).
- Волна дня и таймер не меняются; FSRS не меняется.
- API и MCP лимит не затрагивает: он относится только к обучению.

Критерии готовности: при лимите 10 после 10 знакомств сессия показывает только повторения; «Learn 5 more» добавляет ровно 5; отмена знакомства возвращает 1 в лимит; на следующий день лимит снова 10; для английского и испанского лимиты независимы.

Итог (24.10.2026): всё по плану (D48). Settings → Study — поле «new words per day» для English и Spanish со счётчиком «Today: N of M met». ## MVP-8. Режим ввода ответа

Цель: проверять память точнее, чем самооценкой, — слово нужно напечатать. Запрошено 24.10.2026.

- Перед стартом сессии выбирается способ ответа: «Self-check» (как сейчас) или «Type the answer»; выбор запоминается. Знакомство с новыми словами (intro) не меняется — печатать нужно только при вспоминании.

- После проверки показывается оборот карточки, введённый текст с подсвеченными расхождениями и вердикт приложения.

Критерии готовности: каждый из случаев «верно / почти / неверно / пусто» даёт ожидаемый вердикт; исправление в обе стороны сохраняет именно выбранную оценку и меняет интервал соответственно; повторное нажатие не создаёт второй оценки.

## Recallo: Mobile — веб-приложение для iPhone (W0–W5)

Запрошено 01.11.2026: Recallo на iPhone как отдельная установка — те же экраны и правила обучения, свои данные, без синхронизации с Mac. Вместо MCP — импорт файла, который готовит агент; резервная копия — кнопкой.

Рассмотрены три пути: веб-приложение на экране «Домой», обёртка Capacitor и нативное приложение на Swift. С бесплатным Apple ID приложения из Xcode перестают открываться через 7 дней, а правила обучения на Swift пришлось бы вести вторым экземпляром — выбрано веб-приложение (D57).

Решения пользователя: хостинг — GitHub Pages; на телефон переносится полная копия с Mac (слова и прогресс); проект «Recallo: Mobile», на экране «Домой» — «Recallo».

Устройство:
- правила обучения — те же `src/main/domain` и `src/shared` без изменений;
- база — SQLite, скомпилированный в WebAssembly, в Web Worker, данные — в хранилище браузера (OPFS), схема и миграции те же;
- интерфейс — те же React-экраны; функция `call()` в телефонной сборке шлёт запрос в Worker вместо IPC Electron;
- только для Mac: MCP и Agent API, автокопия в папку, диалоги файлов, `nativeTheme`. На телефоне: импорт и восстановление через выбор файла, «Backup» через меню «Поделиться» с напоминанием о давней копии, подсказки значков — долгим нажатием;
- офлайн — service worker; новая версия — уведомление «Update ready»;
- iOS 17 и новее.
