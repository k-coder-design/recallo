## 2. Архитектура

- **main-процесс Electron**: доменный слой (карточки, наборы, планировщик, очередь), SQLite, REST-сервер (Fastify). Интерфейс и API используют один и тот же доменный слой, поэтому правила одинаковые (API-10).
- **renderer (React)**: интерфейс, общается с main через типизированный IPC.
- **Модель данных** (содержимое, прогресс, история и произношение хранятся раздельно, GEN-06):
  - `cards`: id (UUID), space, term, meaning, set_id?, version, timestamps;
  - `examples`: card_id, text, translation?, mask_fragments[];
  - `sets`: id, space, name, description, version;
  - `card_state`: состояние FSRS (stability, difficulty, due, state, step);
  - `review_log`: id, card_id, rating, source (manual/voice), idempotency_key, created_at, undone;
  - `voice_attempts`: задел под этап 2 (correctness и pronunciation отдельно);
  - `idempotency_keys`: для API.
- **Маскирование**: автопоиск выражения во всех вхождениях без учёта регистра плюс явные фрагменты на каждый пример (CARD-07…09). Предупреждение, если значение содержит ответ.

## 3. Этапы

1. **Каркас**: Electron + Vite + React + TS, SQLite и миграции, доменный слой, тесты (Vitest).
2. **Контент**: пространства EN/ES, наборы и карточки (CRUD), «Без набора», перенос карточек, удаление набора (3 варианта + счётчик), маскирование, поиск, предупреждение о дублях.
3. **Обучение**: выбор области (набор / весь язык), лицевая и обратная сторона, свайп и кнопки, FSRS, очередь (сначала просроченные, перемешивание после ошибки, без бесконечного цикла), счётчики «к повторению / новые», идемпотентная оценка, отмена последней оценки.
4. **Озвучивание** эталона на обратной стороне.
5. **REST API**: все операции из 8.1, токен, OpenAPI с примерами, `Idempotency-Key`, защита версий (`If-Match`/`version` → 409), массовые операции с результатом по каждому элементу, явная политика удаления набора, единая структура ошибок, данные для маскирования.
6. **Импорт/экспорт** CSV/JSON (с отчётом о дублях и ошибках).
7. **Приёмка**: автотесты по критериям раздела 13 (кроме голосовых, п. 6 и 8 переходят на этап 2), сборка `.dmg`.

**Этап 2 (позже)**: выбор сервиса речи, запись, оценка правильности и произношения, правила из таблицы 6.2, повторные попытки без увеличения интервала, уведомление об отправке аудио, ключ в Keychain.
